# Media Sharing Platform

A full-stack media sharing platform built using **FastAPI** and **Streamlit**.
Users can create an account, log in using JWT authentication, upload images and videos, add captions, view posts in a shared feed, and delete their own posts.
Uploaded media is stored using **ImageKit**, while user and post data is managed using **SQLAlchemy** and **SQLite**.
---

## Features
- User registration and login
- JWT-based authentication
- Protected API endpoints
- Image and video uploads
- Media storage using ImageKit
- Add captions to posts
- Shared feed for uploaded posts
- User information associated with posts
- Delete your own posts
- Post ownership authorization
- Asynchronous FastAPI endpoints
- SQLAlchemy database integration
- Streamlit frontend connected to the FastAPI backend
